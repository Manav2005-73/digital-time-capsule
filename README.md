# ChronoCapsule – Digital Time Capsule

ChronoCapsule is a dynamic web application that allows users to write messages for their future selves and choose a date when those messages can be unlocked.

## Features

- Create a digital time capsule
- Set a future unlock date
- Automatically show locked/unlocked status
- Countdown until unlock
- View saved capsules
- Delete capsules
- JSON API for capsule data
- Health check endpoint
- Input validation
- Automated tests
- ESLint code quality checks
